# DivC-PPO project page

Static page for the paper "DivC-PPO: Cartesian-Aligned Credit Assignment for Precision
Vision-Guided End-Effector Positioning". Plain HTML and CSS with no build step.

## Files

- `index.html`: the page. Text and numbers are copied from the paper (`root.tex`, Tables III–V).
- `style.css`: small overrides on Bulma 0.9.4, following the Nerfies project-page template
  (Google Sans and Noto Sans, Font Awesome icons, all loaded from public CDNs).
- `static/hero.json`: per-axis error (mm) per captured step for the hero traces, from the
  `*_p95_v2_s42` capture logs (Ablation 15, seed 42).
- `static/img`, `static/video`: generated by `tools/build_assets.py`.

## Rebuild assets

```
python3 tools/build_assets.py
```

The script needs `pdftocairo`, ImageMagick `convert`, and OpenCV. Its sources are:

- Figures: `Writing/paper/figures/*.pdf`
- Videos: frames in `DualHeadPPO/play_outputs/paper_capture` (Ablation 15, seed 42). Each video's
  frame rate and speed are noted in `tools/build_assets.py` and on the page. Each condition is
  one placement replayed for both policies (`DualHeadPPO/.cache/run_page_v2_capture.sh`).

## Preview

```
python3 -m http.server 8765
```

Then open http://localhost:8765.

## Deploy on Vercel

Import the GitHub repo in Vercel with these settings:

- Framework preset: Other
- Build command: none
- Output directory: `.`
