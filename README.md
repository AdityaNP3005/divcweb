# DivC-PPO project page

Static page for the paper "DivC-PPO: Cartesian-Aligned Credit Assignment for Precision
Vision-Guided End-Effector Positioning". Plain HTML and CSS with no build step.

## Files

- `index.html`: the page. Text and numbers are copied from the paper (`root.tex`, Tables III–V).
- `style.css`: palette taken from Fig. 2 (X/Y/Z red/green/blue, DivC-PPO purple), Source Serif 4 and
  Barlow Semi Condensed, self-hosted under `static/fonts` (SIL OFL, licenses included).
- `static/hero.json`: per-axis error (mm) per captured step for the hero traces. It comes from
  `isaac_captures/logs/*_nominal_seq_s42_capture_log.json` (Ablation 15, seed 42, episode 0).
- `static/img`, `static/video`: generated by `tools/build_assets.py`.

## Rebuild assets

```
python3 tools/build_assets.py
```

The script needs `pdftocairo`, ImageMagick `convert`, and OpenCV. Its sources are:

- Figures: `Writing/paper/figures/*.pdf`
- Hero videos: `isaac_captures/D_sequence_filmstrip`, az60, one frame per 3 policy steps, played at
  10 fps (real time)
- Wrist clips: the `camera_det_*.mp4` files from the Ablation 15 seed 42 play runs in
  `DualHeadPPO/play_outputs`

## Preview

```
python3 -m http.server 8765
```

Then open http://localhost:8765.

## Deploy on Vercel

Import the GitHub repo in Vercel with these settings:

- Framework preset: Other
- Build command: none
- Output directory: `.`
